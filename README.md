# 🎂 Birthday Template

A beautiful and interactive birthday celebration website made with HTML, CSS, and JavaScript.

## 🌐 Live Website

Visit the live website here:

**https://rahul-2005-das.github.io/Birthday-Templete/**

## ✨ Features

* 🎉 Birthday celebration design
* 🎂 Birthday greeting
* 💖 Attractive animations
* 🎵 Background music
* 📱 Responsive design for mobile and desktop
* 🌟 Interactive effects
* 🖼️ Images and birthday memories

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📁 Project Structure

```text
Birthday-Templete/
│

```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
